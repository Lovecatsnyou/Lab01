# Lab01 — Анимация дождя на Python

## Описание проекта

Программа `Main.py` создаёт анимацию дождя с помощью стандартной библиотеки Python **Tkinter**. В окне размером **800 × 500 пикселей** на светло-сиреневом фоне непрерывно падают **150 фиолетовых капель**, изображённых вертикальными линиями.

Капли отличаются длиной, толщиной и скоростью, благодаря чему дождь выглядит более объёмным и естественным.

## Как работает код

1. **Создание окна.** Программа создаёт окно Tkinter и область рисования `Canvas` размером 800 × 500 пикселей с фоном `#E8EAF6`.
2. **Генерация капель.** Для каждой из 150 капель случайным образом задаются координаты и коэффициент `z` от 0.2 до 1.0. От `z` зависят длина, толщина и скорость падения капли.
3. **Отрисовка.** Капли изображаются линиями фиолетового цвета `#6A1B9A`. Информация о каждой капле хранится в списке `drops`.
4. **Анимация.** Функция `update()` сдвигает капли вниз в соответствии с их скоростью и обновляет положение линий на холсте.
5. **Повторное появление.** Когда капля достигает нижней границы окна, она переносится чуть выше верхнего края со случайной горизонтальной координатой, после чего снова падает.
6. **Непрерывное обновление.** Метод `root.after(20, update)` вызывает следующий кадр примерно через 20 мс, а `root.mainloop()` поддерживает работу графического окна.

## Основные параметры

| Параметр | Значение | Назначение |
| --- | --- | --- |
| `W` | `800` | Ширина области анимации в пикселях |
| `H` | `500` | Высота области анимации в пикселях |
| `COUNT` | `150` | Количество капель |
| `z` | От `0.2` до `1.0` | Коэффициент, влияющий на размер и скорость капли |
| `root.after(20, update)` | `20` мс | Интервал между обновлениями анимации |

## Требования

- Python 3.
- Модуль `tkinter` и графическая среда для отображения окна. Tkinter обычно входит в состав Python, но в некоторых системах Linux его нужно установить отдельно.

Сторонние Python-библиотеки не требуются: используются только `random` и `tkinter`.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте терминал в папке проекта.
3. Выполните команду:

```bash
python Main.py
```

Если в вашей системе команда Python 3 называется `python3`, используйте `python3 Main.py`.

После запуска откроется окно с анимацией падающего дождя. Чтобы завершить программу, закройте окно.
